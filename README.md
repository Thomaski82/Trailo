# TRAILO

Responsywny prototyp marketplace'u do wynajmu przyczep w modelach C2C i B2B.

## Uruchomienie lokalne

Projekt jest statyczny i nie wymaga budowania. Otwórz `index.html` w przeglądarce.

## Deployment

Repozytorium można wdrożyć bez dodatkowej konfiguracji w GitHub Pages, Netlify,
Vercel lub Cloudflare Pages. Katalog publikowany to katalog główny repozytorium.

### GitHub Pages

1. Otwórz **Settings → Pages** w repozytorium.
2. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
3. Wybierz gałąź `main`, katalog `/ (root)` i zapisz ustawienia.
